# 明示合成缺陷控制

这些 `.py.txt` 均由维护者对对应正控制源码做一个明确语义修改得到，仅用于检查独立验收对已声明缺陷的敏感度，以及单独的合成缺陷修正实验。它们不是自然模型开发输出，不能混入正常真实开发运行、不能算作自然失败样本。

- `bulk_edit.py.txt`：删除批量 id 去重校验，允许重复 id；应被 `test_batch_validation_is_atomic` 中已声明的重复输入检查拒绝。
- `priority_query.py.txt`：将 query 的优先级排序从降序改为升序；应被排序及相关组合查询检查拒绝。
- `json_merge.py.txt`：成功 import 后不更新 next_id；应被稀疏 id 和后续 add 的分配检查拒绝。

每个文件只有上述一个预设语义缺陷；出现多少失败用例以实际受控容器记录为准，不预填或伪造结果。不得把它们提供给正常模型任务作参考实现。严禁宿主执行。
