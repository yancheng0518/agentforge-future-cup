## 4. 防混淆规则（引用证据前请先对照）

| 类别 | 识别特征 | 可用作什么证据 |
| --- | --- | --- |
| 真实模型（live） | `mode=live`、真实请求数与真实 usage、可在界面看到模型标签 | 单次真实闭环效果；不外推整体成功率 |
| 真实模型 + 预设缺陷 | `seeded` / `synthetic defect` 标注、缺陷在首次调用前冻结 | 修复/复验机制有效；**不能**当作自然失败率或自修正成功率 |
| 模拟（mock） | `模拟模型` 标签、`model_calls=0`、固定修正输出 | 仅证明平台流程与界面可用，不是模型效果证据 |
| 合成/无模型探针 | `sandbox-probe`、验收探针、`0 模型调用` | 隔离、门控与容器边界证据 |
| 平台单元测试 | `tests/` 中 StubRuntime/模拟网络 | 工程回归与契约验证，不是模型评测 |

补充说明：最新交付批次（2026-11-10 交付页与收尾预算）**没有新增模型调用**；其价值在于界面交付顺序、真实 Docker 预览和预算收尾门控，不应用于宣称模型成功率提高。
