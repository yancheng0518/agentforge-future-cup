## 三、评审快速路径

1. **只体验界面**：解压 → 双击 `00_评审入口.html` 了解材料 → 运行 `一键启动.ps1`（无需模型 Key，浏览 09 演示数据中的历史运行、协作图与项目版本）。
2. **验证真实闭环**：按 `08_部署与复现指南/模型接入文档.md` 填写本地 `.env`（评审自备 API Key）→ `部署.ps1 -CheckOnly` → `preflight.py` 退出码 0 → `probe_model.py` 退出码 0 → `一键启动.ps1`。
3. **查证据**：`07_其他说明与证据/证据索引.md` 汇总 9 个复现包 SHA256、真实运行与预设实验的分类；`证据样本/` 提供脱敏 JSON 原始回执（含 2026-11-12「评委模式」真实复现日志：预检 0、探针通过、真实运行 7 请求/21,532 tokens、Docker 验收 10/10 通过）；完整归档在公开仓库 `output/`。

## 四、说明

- 本压缩包不含模型 API Key（评审自备）与运行数据库（演示数据为只读副本，见 `09_演示数据/`）。
- 候选代码只在 Docker 中执行；模型自报结果不作为验收依据。
- 材料中的数字均来自项目真实运行记录与文档；已知边界与未验证项在方案书 §7、§12 与评审版 README 中如实标注。
