# 独立验收与执行边界

完成状态任务的验收位于 acceptance/test_todo.py；扩展任务位于 benchmarks/tasks/<task_id>/test_todo.py，每项固定10个测试。它们仅由平台维护，不接受 Agent 修改。运行时冻结所选任务的需求与验收，再只读挂载；当前 task_contract 是当前任务的完整契约，不把另一任务的约束混入。
候选代码只能在通过预检的 Docker Linux 容器内执行；网络关闭、只读挂载、非 root 用户、资源上限、超时回收。
没有 Docker、镜像或容器运行权限时返回 blocked；不会调用宿主 Python 执行候选。
模拟模型首轮故意漏掉筛选实现，用来演示失败反馈；该故障属于预设演示，不是模型自主犯错的实证。
平台单元测试中的 stub 仅证明编排逻辑，不能作为真实 LLM 或真实容器测试证据。
