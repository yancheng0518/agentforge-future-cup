## 本次范围

支持有界 Python Web 工程：Python 源码与 HTML/CSS/JavaScript/JSON 文本资产，固定入口，PyPI wheel 依赖。第一项实测使用 Flask，不声称支持任意 Node 工程或生产部署。主 Agent 自主编辑/委派、调用 HTTP 工具，验收通过后保存不可变项目版本。

依赖准备只在单独容器中处理固定版本的包；不把候选源码、项目资料或模型密钥放入联网容器。冻结全部传递依赖及 wheel SHA、离线安装镜像 ID。运行容器仍禁网、非 root、只读挂载；不发布 Docker 端口。浏览器通过仅监听本机的独立 origin 代理和受限 iframe 查看真实应用。预览有生命周期和超时，HTTP 运行成功与独立验收分开记账。

## 验证批次（在新模型请求之前声明）

1. **平台条件与依赖准备**：预检、固定 Flask 版本与其实际解析的完整依赖、离线镜像、隔离 HTTP 启动、预览/停止/超时及拒绝越界输入。失败全部留下原始记录。
2. **自然开发**：从维护者编写的最小 Flask 健康页导入新项目，真实模型开发工作项看板（新增、列表、完成状态与筛选，浏览器表单）。既有健康接口必须保留。新增需求未实现导致的导入基线失败单列，不计自然候选失败。
3. **独立交付复核**：维护者事前冻结的 HTTP 用例通过 Docker 检验返回码、数据语义及回归；浏览器操作新增/筛选/完成，并核对真实请求与预览回执。
4. **明示预设缺陷修正**：独立实验副本故意忽略完成状态筛选。先让冻结 HTTP 验收真实失败，再由真实模型修正并重新验收。标明 `seeded_defect`，不混入自然开发成功率；不修改或删除自然实验候选。

自然任务计划使用一次提交，最多 40 请求、300,000 tokens、8,192 输出 token、24 步、8 次验证、1,800 秒。协议/平台阻塞不能悄悄重跑；需要新尝试时先追加理由和独立运行 ID，原失败留在分母。自然首轮通过时，不能拼接预设缺陷证明自然自修复。
