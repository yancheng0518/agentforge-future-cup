## 已实现

- React/TypeScript 工作台与 FastAPI/SQLite 后端，平台和受控 Todo 示例分离。
- 五类 Agent 的编辑、启停、版本快照；按能力、工具授权、依赖、优先级与负载选择 Agent，记录分配理由。
- 开发/审查两套代码化模板；并行测试与静态初审、最终审查、条件门控、最多两轮反馈修正。
- 受控文件读取与候选写入、真实 diff、带来源的关键词知识检索。
- SQLite 事件、原子节点检查点、失败恢复、候选哈希验证与基线冲突保护；应用前必须用户明确确认。
- 真实聊天接口、JSON 契约、有限轮只读工具调用；智云 V4 显式关闭思考模式；未知 usage 与失败请求不记成完整零用量。
- native/WSL Docker 后端、Windows/WSL 路径转换、进程超时清理；平台授权错误与服务渠道错误分开提示。
- 十项独立验收及可信父进程/候选 worker RPC；同一测试的多个实例共享 worker，能检查 class 共享状态与返回引用别名。
- 验证上下文按轮次与候选哈希隔离；静态初审与最终结果审查职责区分。
- 第一轮成功时 UI 的修正分支显示“已跳过”，避免把没有执行的修正显示为完成或待执行。
- 四项任务目录、需求/基线/验收快照与哈希、每轮候选归档、前端任务选择与候选导出；扩展任务强制真实模型且不覆盖评测基线。
- 批量预注册评测与完整导出、区分自然代码失败/协议失败/预设缺陷；观察器中断可以继续观察同一运行，不重复提交。
- 每节点总共四次请求，前两次允许只读工具，预留至多一次 JSON 契约重试；原错误与重试计量持久化。服务取消保留已知用量，容器启动异常不宣称隔离执行。
- 三策略配对对照运行器：单 Agent、固定串行、动态并行；相同 HTTP/输出/正文/时间预算上限，逐请求归档、统一独立功能终点与原生门控分开统计。
- 观察器 Windows 原子写入有限重试；只对未提交槽位另建预注册采集阶段，永久领取记录防重复提交，联合报告保留原分母与阶段中断。
- 预检、锁定依赖安装、Docker 安装/启动、模型探测、真实运行导出、合成缺陷真实修正实验及复现说明。
